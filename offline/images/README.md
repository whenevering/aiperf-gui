# Offline image files

Place Docker image archives in this directory before moving the kit into the
offline environment.

Expected files for the current kit:

- `aiperf-base-0.12.0.tar`
- `aiperf-base-0.12.0.sha256`
- `aiperf-gui-0.1.0-2026-08-31.tar.gz`
- `aiperf-gui-0.1.0-2026-08-31.tar.gz.sha256`

The AIPerf GUI image is published in the GitHub Release:

```text
https://github.com/whenevering/aiperf-gui/releases/tag/aiperf-gui-0.1.0-2026-08-31
```
